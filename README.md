## Дизайн і верстка

Палітра - CSS-змінні в `:root`, основний колір `#0D7B7B`.

Шрифти: Alegreya (заголовки) та Inter (текст).

## Адаптивність

Брейкпоінти: 1024 px (планшет) і 640 px (телефон), без горизонтального скролу.

## JavaScript

- `js/index.js` - модальне вікно швидкого замовлення.
- `js/order.js` - перевірка полів форми замовлення, передвибір послуги з адреси, підсумок замовлення.

## Додаткова вимога «замовника»

**Вимога № 18:** яскрава двоколірна градієнтна плашка під кожним заголовком H1-H3.

**Стратегія:** компроміс. Плашка лише під заголовками розділів H2, суцільного тону з палітри (`--color-sand-dark`): градієнт під кожним заголовком знижує контраст тексту, виходить за затверджену палітру і перевантажує сторінку на телефоні.

## Запуск

Сайт статичний: відкрити `index.html` у браузері або перейти за посиланням на GitHub Pages.

```
web_assignment/
  index.html  services.html  order.html  about.html
  css/   index.css  services.css  order.css  about.css
  js/    index.js  order.js
```
